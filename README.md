# Luma Skin — Product & QR Code Management System

ระบบจัดการข้อมูลสินค้าภายในองค์กรสำหรับแบรนด์ **Luma Skin** รองรับการนำเข้าข้อมูลสินค้าจากไฟล์ Excel (`.xlsx`), การจัดการรูปภาพตามเงื่อนไข, การสร้างและปรับแต่ง QR Code รายสินค้า รวมถึงหน้าแสดงข้อมูลสินค้าสาธารณะสำหรับลูกค้าที่สแกน QR Code จากบรรจุภัณฑ์

- **เวลาที่ใช้ในการพัฒนาทั้งหมด:** ใช้เวลารวม 3 ชั่วโมง [XX] นาที 
---

## 1. วิธีติดตั้งและรันระบบ (Installation & Setup)

### ข้อกำหนดเบื้องต้น (Prerequisites)
- Python 3.10 ขึ้นไป

### ขั้นตอนการติดตั้งและรันเซิร์ฟเวอร์ (Windows PowerShell)
```powershell
# 1. Clone หรือเข้าไปยังโฟลเดอร์โปรเจกต์
cd yes-dev-test

# 2. สร้างและเปิดใช้งาน Virtual Environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 3. ติดตั้ง Dependencies ทั้งหมด
pip install -r requirements.txt

# 4. รันเซิร์ฟเวอร์ FastAPI (ระบบจะสร้างฐานข้อมูล lumaskin.db และ Seed บัญชีให้อัตโนมัติ)
uvicorn main:app --reload
```

## 2. Tech stack ที่เลือก และเหตุผลที่เลือก

- **Backend**: Python + FastAPI เนื่องจากเร็วและเหมาะสำหรับ
- **Database**: SQLite
- **Fontend**: HTML + Tailwind CSS + Vanilla JS

## 3. ฟีเจอร์ที่ทำเสร็จ และที่ไม่เสร็จ

1. **ฟีเจอร์ที่พัฒนาเสร็จสมบูรณ์ (Completed)**
- [x] Authentication: ระบบเข้าสู่ระบบ (ไม่มีหน้าสมัครสมาชิกสาธารณะ) แยกสิทธิ์
- [x] Excel Import (Sanitization + Validation + Upsert):
    - ข้ามแถวว่างอัตโนมัติ, ตัดช่องว่างและแปลง sku เป็นตัวพิมพ์ใหญ่, รองรับราคาที่มีลูกน้ำคั่น (1,290)
    - ตรวจจับ sku ซ้ำภายในไฟล์เดียวกัน, ตรวจสอบรูปแบบ LS-0000, หมวดหมู่, ราคา (> 0) และสถานะ
    - รายงาน Error แยกตามเลขแถวและสาเหตุชัดเจนโดยไม่ทำให้แถวที่ถูกต้องเสียหาย
    - อัปเดตข้อมูลซ้ำตาม sku (Upsert) โดย ไม่ลบรูปภาพเดิม ที่อัปโหลดไว้แล้ว
- [x] Product Management & Image Validation: ค้นหา/กรองสินค้า แก้ไขรายละเอียด เปลี่ยนสถานะ active/inactive และอัปโหลดรูปภาพพร้อมตรวจชนิดไฟล์ (JPG, PNG, WEBP), ขนาดไม่เกิน 2 MB และความละเอียดขั้นต่ำ 800 x 800 px
- [x] QR Code Generation & Customization: สร้าง QR Code ผูกกับ /p/{sku} ปรับเปลี่ยนสีตัว QR สีพื้นหลัง และขนาด (SM, MD, LG) พร้อมพรีวิวแบบ Real-time และดาวน์โหลดเป็น .png
- [x] Public Product Page (/p/{sku}): หน้าแสดงข้อมูลสินค้าสำหรับลูกค้าบนมือถือ แยกการแสดงผลกรณี active, inactive (แจ้งไม่พร้อมจำหน่าย) และไม่พบสินค้า
- [x] Scan Analytics (scan_logs): บันทึกประวัติการสแกนพร้อม User-Agent และสรุปอันดับสินค้าที่ถูกสแกนดูมากที่สุด (Top 5) บนหน้า Dashboard
- [x] Invite Admin & Audit Log: Super Admin สร้างคำเชิญ Admin ใหม่พร้อมลิงก์ตั้งรหัสผ่าน (/accept-invite) และบันทึก Log ลงไฟล์ invite_logs.log

2. **ฟีเจอร์ที่ยังไม่เสร็จ / ข้อจำกัดปัจจุบัน (Incomplete / Limitations)**
- [ ] การส่งอีเมลจริงผ่าน SMTP: ระบบเชิญ Admin ใหม่ใช้วิธีสร้าง Token และลิงก์รับคำเชิญพร้อมบันทึก Audit Log ลงไฟล์ invite_logs.log แทนการส่งอีเมลผ่าน SMTP Server จริง เพื่อให้ทดสอบ Flow การเปิดใช้งานบัญชีได้ทันทีในสภาพแวดล้อม Local
- [ ] Bulk Download QR Code (ZIP): ปัจจุบันรองรับการดาวน์โหลด QR Code รายสินค้า ยังไม่ได้เพิ่มปุ่มดาวน์โหลดทั้งหมดเป็นไฟล์ .zip ในครั้งเดียว

## 4. สิ่งที่ต่างจากแผนงาน และเหตุผลที่เปลี่ยน

- เพิ่มคอลัมน์แสดงรายละเอียดการสแกนล่าสุด (Recent Scans) ในหน้า Dashboard:
    - แผนเดิม: วางแผนแสดงเฉพาะสรุปอันดับสินค้าที่ถูกดูมากที่สุด
    - สิ่งที่เปลี่ยนและเหตุผล: เพิ่มตารางประวัติการสแกน 10 รายการล่าสุดพร้อมเวลาและข้อมูลอุปกรณ์ (user_agent) เพื่อให้ง่ายต่อการตรวจสอบว่าเมื่อลูกค้าสแกน QR Code แล้วระบบบันทึก Log ลงฐานข้อมูลจริงทันที
- การปรับแต่ง QR Code ย้ายมาอยู่ในหน้าแก้ไขสินค้า (/products/{id}/edit):
    - แผนเดิม: แยกเมนู QR Code Management ออกเป็นอีกหน้าหนึ่ง
    - สิ่งที่เปลี่ยนและเหตุผล: รวมไว้ในหน้าเดียวกับการจัดการข้อมูลและรูปภาพของสินค้านั้นๆ เพื่อลดจำนวนคลิกของ Admin และสามารถโหลด QR มาตรฐานได้ทันทีจากตารางรายการสินค้า

## 5. การใช้ AI: ใช้ทำอะไรบ้าง, ตัวอย่าง prompt อย่างน้อย 3 ตัวอย่าง, AI ผิดพลาดตรงไหนและแก้อย่างไร, ส่วนไหนเขียนเองทั้งหมด

1. **ใช้ AI ช่วยทำอะไรบ้าง**
- วางโครงสร้างโปรเจกต์ FastAPI, ออกแบบ schema.sql และแปลงเงื่อนไขการตรวจสอบข้อมูล Excel / รูปภาพให้เป็นฟังก์ชันใน services.py
- วางโครงสร้างโปรเจกต์ FastAPI, ออกแบบ schema.sql และแปลงเงื่อนไขการตรวจสอบข้อมูล Excel / รูปภาพให้เป็นฟังก์ชันใน services.py
- ช่วยตรวจสอบสาเหตุของ Error ระหว่างการรันฐานข้อมูลและปรับปรุงเอกสาร README.md

2. **ตัวอย่าง Prompt ที่ใช้ในการพัฒนา (3 ตัวอย่าง)**
- นี่คืแผนงานในการเตรียมสร้างระบบจัดการสินค้าที่นำเข้าข้อมูลจาก Excel แล้วสร้าง QR ให้สินค้าแต่ละชิ้น เมื่อสแกนจะเห็นหน้าเว็บข้อมูลสินค้านั้น ระบบนี้ใช้เฉพาะ Admin ภายใน ไม่มีการสมัครสมาชิกจากภายนอก 
- ข้อมูลเพื่มเติม Tech Stack ที่จะใช้ มีดังนี้
    -backend : Python + FastAPI
    -database : SQLite
    -fontend : HTML + Tailwind CSS + Vanilla JS
โดยจะเริ่มจาก phase1 วิเคราะห์ข้อมูลจากไฟล์ Excel ตัวอย่าง วางโครงสร้างฐานข้อมูล จัดลำดับความสำคัญ 
- เยี่ยม ต่อไปทำ phase2 สร้าง Environment, ไฟล์ schema.sql, ระบบเชื่อมต่อ SQLite, Seed บัญชี Super Admin และระบบ Login + แยกสิทธิ์ Role
- เยี่ยม ต่อไปทำ phase3 สร้างระบบนำเข้าไฟล์ .xlsx (Validation + Upsert + รายงาน Error รายแถว), หน้าจัดการรายการสินค้า, แก้ไขข้อมูล และอัปโหลดรูปภาพพร้อมตรวจเงื่อนไข

3. **จุดที่ AI ผิดพลาดและวิธีการแก้ไข**
- ปัญหาโครงสร้างตารางเก่าค้างใน SQLite
    - สาเหตุ: โค้ด init_db() ใช้คำสั่ง CREATE TABLE IF NOT EXISTS ทำให้เมื่อไฟล์ lumaskin.db เดิมมีคอลัมน์ username ค้างอยู่จากโครงสร้างเก่า คำสั่ง Seed ข้อมูลใหม่ที่ใช้ email จึงเกิด Error ตอนเปิดเซิร์ฟเวอร์
    - วิธีแก้ไข: วิเคราะห์ Traceback ลบไฟล์ lumaskin.db เก่าออกแล้วรัน uvicorn ใหม่เพื่อให้สร้างตารางตาม schema.sql ล่าสุดทั้งหมด

4. **ส่วนที่พัฒนาและตรวจสอบด้วยตนเองทั้งหมด**
- วิเคราะห์โครงสร้างคอลัมน์และกฎการทำความสะอาดข้อมูล (Sanitization Rules) จากไฟล์ Excel ตัวอย่างของโจทย์ (sku, price, การจัดการแถวว่าง และเงื่อนไข Upsert)
- วางลำดับความสำคัญของงาน (P0/P1/P2) และขอบเขตการตัดฟีเจอร์ใน PLAN.md
- ทดสอบ End-to-End ด้วยไฟล์ Excel ทั้ง 2 รอบ ทดสอบอัปโหลดรูปภาพที่ผิดเงื่อนไข (ขนาดเล็กกว่า 800x800 px และไฟล์เกิน 2 MB) และทดสอบสแกน QR Code ผ่านหน้าต่างไม่ระบุตัวตน (Incognito)
